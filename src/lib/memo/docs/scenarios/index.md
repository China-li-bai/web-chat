## 🎯 使用指南

### 选择合适的场景
1. **确定学习目标** - 明确要掌握的知识类型
2. **评估当前水平** - 选择适合的难度起点
3. **设定学习计划** - 制定合理的时间安排
4. **跟踪学习进度** - 定期查看统计报告

### 自定义配置
每个应用场景都可以根据具体需求进行配置调整：

```typescript
// 示例：语言学习配置
const languageLearningConfig = {
  fsrsConfig: {
    requestRetention: 0.88, // 语言学习需要较高保留率
    maximumInterval: 90,    // 最大3个月复习间隔
  },
  adaptiveConfig: {
    adaptationRate: 0.2,    // 较快的难度适应
    cognitiveLoadThreshold: 0.7
  },
  retrievalConfig: {
    testingEffectWeight: 0.4,    // 重视测试效应
    spacingEffectWeight: 0.35,   // 间隔效应
    generationEffectWeight: 0.25 // 生成效应
  }
};
```

### 集成到现有系统
所有场景都基于统一的 `MemoryLearningManager` 接口，可以轻松集成到现有应用中：

```typescript
import { MemoryLearningManager } from '../MemoryLearningManager';
import { EnglishVocabularyApp } from './scenarios/language-learning';

// 创建特定领域的学习应用
const vocabApp = new EnglishVocabularyApp();
const session = await vocabApp.createPersonalizedVocabularySession(
  'user-123', 
  'intermediate', 
  1200
);
```
