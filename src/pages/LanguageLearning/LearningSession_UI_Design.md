# 语言学习会话页面UI重设计方案

## 1. 设计理念与原则

### 1.1 核心设计理念
基于INTJ视角+乔布斯思维模式+逆向批判性思维，我们追求**极简但功能强大**的设计，专注于核心学习体验，减少认知负荷，同时确保数据流的一致性和响应式布局的完美实现。

### 1.2 设计原则
- **移动优先**：以移动端体验为核心，桌面端作为增强
- **极简主义**：减少视觉干扰，突出核心内容
- **数据一致性**：确保所有数据展示和交互保持统一
- **微交互增强**：通过精心设计的动画和反馈提升用户体验
- **无障碍设计**：确保所有用户都能顺畅使用

## 3. 信息架构与数据流

### 3.1 页面结构
```
┌─────────────────────────────────────┐
│ 顶部状态栏 (进度、模式、统计)          │
├─────────────────────────────────────┤
│                                     │
│         学习卡片区域                  │
│    (支持多种题型: 卡片/选择/拼写)      │
│                                     │
├─────────────────────────────────────┤
│       底部操作区 (拇指友好)            │
│    (Again/Hard/Good/Easy)           │
└─────────────────────────────────────┘
```

### 3.2 数据流设计
1. **分段学习数据流**：
   - 从全局学习队列中分段加载(8-12词/段)
   - 每段独立统计，段末提供简短反馈
   - 段与段之间无缝过渡，保持学习节奏

2. **响应数据流**：
   - 用户反馈实时更新本地状态
   - 批量提交至服务器，减少网络请求
   - 离线优先设计，弱网环境下仍可学习

3. **跨书统一队列**：
   - 多本书的学习内容合并到统一队列
   - 智能调整新词与复习比例
   - 基于遗忘算法优化复习时机

## 4. 组件设计与交互规范

### 4.1 顶部状态栏
- **设计**：简洁的条状区域，显示关键信息
- **内容**：
  - 左侧：学习模式标签(全局/词书)
  - 中间：段内进度(当前/总数)和进度条
  - 右侧：今日学习统计
- **响应式**：移动端精简显示，桌面端展示更多细节
- **交互**：点击可展开详细统计面板

### 4.2 学习卡片区域
- **卡片设计**：
  - 圆角矩形，轻微阴影，3D翻转效果
  - 正面：核心内容(单词/问题)
  - 背面：详细信息(释义/例句/音标)
  - 尺寸：响应式，移动端占屏幕70%宽度，桌面端固定最大宽度
- **题型支持**：
  - 卡片翻转：默认模式
  - 选择题：2×2或3×2网格布局
  - 拼写题：大字体输入框，实时反馈
  - 听写题：音频播放按钮+输入框
- **交互**：
  - 点击翻转或显示答案
  - 手势支持：左右滑动切换，长按显示提示
  - 键盘快捷键：Enter翻转，数字键选择答案

### 4.3 底部操作区
- **设计**：固定在底部，拇指友好区域
- **按钮**：
  - Again(红色)：完全不记得
  - Hard(橙色)：模糊记得
  - Good(蓝色)：记得清楚
  - Easy(绿色)：非常简单
- **尺寸**：移动端高度≥44px，全宽按钮
- **交互**：
  - 点击后立即反馈(动画+声音)
  - 自动进入下一题
  - 支持键盘快捷键(1-4)

### 4.4 段末反馈
- **设计**：简短的模态卡片，非全屏遮罩
- **内容**：
  - 本段学习统计(正确率/用时)
  - 掌握情况分布(已掌握/生疏/遗忘)
  - 下一段学习建议
- **交互**：
  - "继续下一段"：无缝衔接
  - "稍后休息"：暂停学习
  - "查看详情"：展开完整统计

## 5. 响应式设计规范

### 5.1 断点设置
- **移动端**：< 768px
- **平板端**：768px - 1024px
- **桌面端**：> 1024px

### 5.2 移动端优化
- **布局**：单列布局，垂直排列
- **导航**：底部固定操作区，便于拇指操作
- **字体**：最小16px，确保可读性
- **间距**：至少8px，避免误触
- **手势**：支持滑动、长按等常见手势

### 5.3 桌面端增强
- **布局**：可利用水平空间，显示更多信息
- **导航**：支持键盘快捷键
- **交互**：鼠标悬停效果，更精细的反馈
- **信息密度**：可显示更多统计数据和选项

## 6. 微交互与动画设计

### 6.1 卡片翻转
- **效果**：3D翻转，0.6s缓动
- **反馈**：轻微阴影变化，增强立体感
- **触发**：点击卡片或"显示答案"按钮

### 6.2 按钮反馈
- **点击**：轻微缩放(0.95) + 颜色加深
- **释放**：弹性恢复 + 波纹效果
- **声音**：轻量反馈音(可关闭)

### 6.3 进度动画
- **进度条**：平滑增长，0.3s缓动
- **数字变化**：计数动画，增强成就感
- **里程碑**：特殊效果(如完成一段)

## 7. 无障碍设计

### 7.1 键盘导航
- **Tab顺序**：逻辑清晰，覆盖所有交互元素
- **快捷键**：常用功能有键盘快捷方式
- **焦点指示**：清晰可见的焦点样式

### 7.2 屏幕阅读器
- **语义化HTML**：正确使用标签和ARIA属性
- **替代文本**：为所有图像和图标提供描述
- **状态通知**：重要状态变化及时通知

### 7.3 视觉辅助
- **对比度**：至少4.5:1的文字对比度
- **字体大小**：可缩放至200%不失功能
- **颜色依赖**：不仅依赖颜色传达信息

## 8. 性能优化

### 8.1 加载优化
- **懒加载**：分段加载学习内容
- **预加载**：提前加载下一段内容
- **缓存策略**：合理使用浏览器缓存

### 8.2 动画优化
- **GPU加速**：使用transform和opacity
- **减少重绘**：避免布局抖动
- **简化动画**：移动端减少复杂动画

## 10. 技术实现要点

### 10.1 组件结构
```
LearningSessionPage
├── SessionTopBar (状态栏)
├── FlashcardArea (卡片区域)
│   ├── Flashcard (卡片翻转)
│   ├── ChoiceQuestion (选择题)
│   ├── SpellingQuestion (拼写题)
│   └── ListeningQuestion (听写题)
├── SessionActionsBar (底部操作区)
└── SegmentSummary (段末反馈)
```

### 10.2 状态管理
- 使用React Hooks管理本地状态
- 分段数据流，避免大量数据渲染
- 乐观更新，提升响应速度

### 10.3 样式实现
- 使用CSS Grid和Flexbox实现响应式布局
- CSS变量管理主题和尺寸
- 使用transform实现高性能动画
