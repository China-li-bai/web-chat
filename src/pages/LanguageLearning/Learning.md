## 核心功能
单词本选择与管理: 用户可以浏览、选择不同的单词本进行学习。界面会清晰展示每个单词本的名称、总词汇量以及当前学习进度。
间隔重复学习会话: 这是学习的核心界面。系统会根据src/lib/memo中的记忆算法，智能地推送需要复习或学习的新单词。用户通过“认识”或“不认识”等交互，反馈对单词的掌握情况，系统随即更新该单词的下一次复习时间。界面设计将采用极简的卡片式，正面显示单词，背面显示释义和例句，确保用户能专注于学习本身。
学习数据统计与可视化: 系统会记录用户的学习历史，并在一个专门的统计页面上进行可视化展示。通过图表（如学习日历热力图、掌握程度分布图）直观地呈现用户的学习频率、已掌握词汇量和整体进度，以激励用户持续学习。
## 语言学习模块 UI/UX 设计方案
Style Guide
整体设计遵循**极简主义（Minimalism）**风格，旨在为用户创造一个沉浸、无干扰的学习环境。

主题与氛围: 界面以简洁、专注、高效为核心理念。通过大量的留白、清晰的结构和柔和的视觉元素，减少用户的认知负荷，使其能完全投入到单词记忆中。
色彩方案:
主色调: 采用柔和的灰色系（#F4F4F5）作为背景，营造宁静、舒适的视觉感受。
强调色: 使用平静而清晰的蓝色（#3B82F6）作为交互元素和关键信息的强调色，如按钮、进度条和链接，引导用户操作。
文本颜色: 主要使用深灰色（#18181B），保证最佳的可读性。
布局与栅格: 采用基于 8pt 网格系统的响应式布局。桌面端使用12列栅格，确保内容在不同屏幕尺寸下都能优雅地展示。核心学习区域将始终保持在屏幕中央，两侧留有充足的边距。
字体: 选择现代、清晰的无衬线字体（如 Inter 或系统默认字体），优化屏幕阅读体验。通过字重和字号的变化来构建清晰的信息层级。
交互与动效: 交互动效将是微妙且有意义的。例如，卡片翻转采用平滑的3D过渡效果，按钮点击有轻微的缩放反馈。所有动效都旨在提升体验的流畅性，而非分散注意力。
Page Structure
1. 单词本选择页 (Wordbook Selection)
此页面是用户开始学习的入口。

顶部导航栏 (Top Navigation Bar): 左侧为应用Logo和“单词学习”标题，右侧为用户头像和设置入口。
单词本网格列表 (Wordbook Grid): 页面主体部分是一个响应式网格布局，每个网格单元是一个单词本卡片。
卡片设计: 卡片采用圆角矩形和轻微的阴影，营造柔和的立体感。
卡片内容: 显示单词本封面（或图标）、标题、总词汇量和一个表示学习进度的环形进度条。
交互: 鼠标悬停在卡片上时，卡片会轻微上浮，并显示“开始学习”按钮。
2. 学习会话页 (Learning Session)
这是单词记忆的核心界面，设计上追求极致的专注。

会话进度条 (Session Progress Bar): 页面顶部有一条纤细的进度条，实时显示当前学习会话的完成进度（例如 15/50）。
单词卡片 (Flashcard): 页面中央是核心的单词卡片。
卡片正面: 只显示当前需要学习或复习的单词，字体较大，位置居中。
卡片背面: 显示单词的详细信息，包括音标、释义、例句等。信息排版清晰，主次分明。
翻转交互: 用户点击“显示答案”按钮或卡片本身，卡片会平滑地翻转到背面。
交互按钮组 (Interaction Buttons): 卡片下方是用户的反馈按钮。在显示答案后出现，通常包括“忘记了”、“模糊”、“记住了”等选项，按钮设计简洁，仅用文字和颜色区分。
退出按钮 (Exit Button): 页面右上角提供一个“结束本次学习”的图标按钮，允许用户随时中断学习。
3. 学习统计页 (Statistics Dashboard)
此页面用于可视化用户的长期学习成果。

核心数据摘要 (Key Metrics Summary): 页面顶部是几个关键数据指标卡片，如“已掌握单词总数”、“今日需复习”、“累计学习天数”。
学习日历热力图 (Activity Heatmap): 一个类似于 GitHub 贡献图的日历视图，根据每日学习的单词数量显示不同的颜色深度，直观展示用户的学习频率和连续性。
掌握程度分布图 (Proficiency Chart): 使用环形图或条形图，展示用户词汇库中处于“新词”、“学习中”、“已掌握”等不同阶段的单词分布情况。
复习计划表 (Review Schedule): 一个简洁的列表，显示未来一周内每天预计需要复习的单词数量，帮助用户规划学习。
