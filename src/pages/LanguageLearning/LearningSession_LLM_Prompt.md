## 常见问题解决

### 卡片翻转问题
如果3D翻转效果不理想，尝试：
1. 检查perspective值设置
2. 确保backface-visibility: hidden
3. 使用transform而非position变化
4. 添加硬件加速（transform: translateZ(0)）

### 响应式布局问题
如果布局在不同尺寸下表现不一致：
1. 检查flex和grid设置
2. 确保容器有明确的宽度/高度
3. 避免固定尺寸，使用相对单位
4. 检查媒体查询断点设置

### 性能问题
如果动画卡顿：
1. 使用will-change属性
2. 减少box-shadow使用
3. 避免复杂的CSS选择器
4. 使用React.memo优化渲染
