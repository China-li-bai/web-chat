## 功能架构分析

### 游戏模式设计
根据页面提取信息，游戏包含三种模式：

1. **热身模式**
   - 慢节奏显示
   - 仅显示单词
   - 难度：简单

2. **记忆模式**
   - 中速节奏
   - 需要用户输入单词
   - 难度：中等

3. **挑战模式**
   - 快节奏
   - 包含句子和习语
   - 难度：困难

### 交互系统
- **分数系统**: 当前分数显示（初始为0）
- **连击系统**: 连续正确答题计数
- **进度系统**: 当前进度显示（1/20）
- **控制按钮**: 开始游戏、暂停(⏸️)、确认
- **输入系统**: 文本输入框（占位符：输入单词...）
