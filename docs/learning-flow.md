# 英语词汇学习流程（FSRS 与分散复习整合版）

本指南整合“分散复习（Spaced Repetition）”与 FSRS 思路，给出四个平台可直接发布的 ENFP 风格推广文案（含示例段），支持表情符号与访问链接。

## 一、核心方法（简述）
- 语块化输入：词 + 2 条地道例句 + 搭配/近反义
- 首次吸收：理解含义 → 朗读 → 用自己的句子造句
- 间隔复习：按 FSRS 曲线安排 D1 / D3 / D7 / D14 / D30（难词缩短，易词拉长）
- 情境产出：在“职场/生活/社媒”三域进行复述/表达，形成可用语感
- 追踪指标：熟练度分（0-5）、遗忘率阈值（≥0.4 触发短间隔）、语块留存率（≥70% 进入月度回看）

示例模板（可复制使用）
词：robust（稳健、强韧）  
例句1：We need a robust plan to handle uncertainty.  
例句2：This system is robust against failures.  
我的句子：Our workflow became more robust after automation.  
复习计划：D1✅ D3✅ D7⏳ D14⏳ D30⏳  
产出任务：  
- 职场：Describe a “robust” process in 2 sentences  
- 生活：举一个“robust”的习惯（晨跑/阅读）  
- 社媒：用 robust 写一条简短分享
