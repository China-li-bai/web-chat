

```typescript
// 改进方案
const cleanupOldData = () => {
  const cutoffDate = new Date();
  cutoffDate.setMonth(cutoffDate.getMonth() - 3); // 3个月前的数据
  
  set((draft) => {
    // 清理过期的学习数据
    Array.from(draft.learningProgress.words.entries())
      .filter(([_, progress]) => progress.lastReview < cutoffDate)
      .forEach(([wordId, _]) => {
        draft.learningProgress.words.delete(wordId);
      });
  });
};
```

### ⚠️ 安全风险

#### 1. **缺乏访问控制**

**风险**: 任意用户可能访问其他用户数据  
**建议**: 添加用户身份验证和授权检查

```typescript
// 改进建议
startGame: async (params: StartGameParams) => {
  // 验证用户身份
  const userId = getCurrentUserId();
  if (!userId || userId !== params.userId) {
    throw new Error('Unauthorized access');
  }
  
  // 验证词书访问权限
  const hasAccess = await checkWordbookAccess(userId, params.wordbookId);
  if (!hasAccess) {
    throw new Error('Access denied to wordbook');
  }
  
  // 创建会话
  const session = await gameService.createGameSession(params);
}
```

#### 2. **敏感数据处理**
